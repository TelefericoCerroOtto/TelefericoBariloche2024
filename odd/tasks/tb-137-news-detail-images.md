# TB-137 News detail images

## Objective

Allow editors to provide optional mobile and desktop images for news detail pages using the existing Strapi `utils-components.image` component. Render each viewport-specific image when present and fall back independently to the existing required cover. Give the image pipeline a distinct matching profile without changing the existing cover profile's output contract.

## Problem and motivation

The required news cover currently serves both the existing news surfaces and the full-width detail image. A single cover cannot be authored for the detail page's distinct mobile and desktop proportions without changing other surfaces or cropping behavior. Optional detail-only assets let editors match the fixed 550px-tall detail geometry while preserving the existing cover as a reliable fallback.

## Scope and constraints

- Add optional mobile and desktop `utils-components.image` fields for news detail use, expose their nested media through the detail API, and render them responsively in the app. Each viewport must independently fall back to the existing required cover when its component or nested media is absent. Keep the required existing `cover` field as raw media and do not change its behavior.
- Base the image ratios on the actual full-width, fixed 550px news-detail image geometry: approximately 2:3 on mobile and 21:9 on desktop near a 1280px viewport. Treat these as distinct output slots in a new matching Image Pipeline profile; preserve the configured geometry rather than introducing crop changes.
- Rename the existing ignored local Studio profile `news-portrait` to a name that includes `cover`. Preserve its `standard-16x9` slot at 16:9, 2.5 MP, quality 95, WebP. Keep its existing local workspace assignment, which uses `profileId` and is confirmed to reference `portada_noticia_mundial.png`.
- Do not change card, featured-news, or required-cover image behavior, output, or crop. Do not replace the cover or silently change the assignment's referenced profile.
- Editing is Strapi-only unless implementation evidence shows the dashboard must change to satisfy the contract. Do not expand dashboard editing preemptively.
